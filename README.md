## 🏗️ Projects

### 🔒 [Virtual Firewall & Network Security Home Lab](https://github.com/jorger31/pfSense-Network-Lab)
> Built a fully functional network security lab using pfSense, WireGuard VPN, and Snort IPS entirely on virtual machines

- Deployed pfSense as a virtual firewall with stateful packet inspection and custom firewall rule policies
- Configured NAT and port forwarding to simulate hosting a web server behind a firewall
- Implemented WireGuard VPN server with public key infrastructure for encrypted tunneling
- Integrated Snort IPS with Emerging Threats and GPLv2 rulesets for real-time intrusion detection

**Tools:** pfSense · VirtualBox · Ubuntu Server · WireGuard · Snort · Apache · Nmap

---

### 🏢 [Active Directory Home Lab — Threat Detection & Adversary Emulation](https://github.com/jorger31/Active-Directory-VM)
> Built a Windows domain environment with a dedicated attacker machine, Splunk SIEM, and adversary emulation using Atomic Red Team

- Deployed Active Directory Domain Services and managed users, groups, and Group Policy Objects
- Configured Splunk SIEM with Universal Forwarders on all endpoints for centralized log collection
- Installed Sysmon for enhanced endpoint telemetry capturing process creation, network connections, and registry modifications
- Conducted adversary emulation using Atomic Red Team (MITRE ATT&CK) and Kali Linux to simulate real-world attacks
- Built Splunk detection queries to identify indicators of compromise across the domain

**Tools:** Windows Server · Windows 10 · Kali Linux · Splunk · Sysmon · Atomic Red Team · VirtualBox
